# GameDeck roadmap

## Now — dependable foundation

- Signed Windows installer and portable build
- Universal macOS release with notarization
- Linux AppImage and Debian package
- Portable emulator/library discovery and setup diagnostics
- Controller-complete Community and Settings surfaces
- Reproducible release artifacts and checksums

## Next — the best library experience

- Per-system emulator selection and launch profiles
- Safer first-run onboarding and automated core detection
- Cloud-optional save backup adapters
- Accessibility presets, screen-reader review, and reduced-motion polish
- Theme and localization contribution kits
- Curated plugin API with permission boundaries

## Later — community scale

- Opt-in metadata providers and artwork provenance
- Signed community integrations
- Crash reports that are local by default and explicitly user-submitted
- Sponsor inventory and transparent funding dashboard

Roadmap order can change based on security, platform breakage, maintainer capacity, and community evidence.
