## Post-audit evidence addendum — 2026-08-02 21:45 ET

The following checks were completed after the original baseline and are verified through commit `7b7ecba`. They extend the evidence above without changing the original audited-base record.

### Invitation input boundaries and live regression

- Commit `e495c8d` limits synchronized `GDPLAY1` text to 32 KiB and its decoded payload to 24 KiB, requires strict Base64URL input, and returns specific malformed, incomplete, oversized, expired, or incompatible-version errors.
- Remote Play codes are limited to 64 KiB of text, 48 KiB of compressed data, and 256 KiB of decoded data. Brotli decoding uses an explicit output limit before JSON parsing.
- A live Metal Slug 3 synchronized host reached the New York relay, generated a 760-character `GDPLAY1` invitation, and the normal join path reached `ready` with 2/2 players.
- Two isolated GameDeck profiles completed the normal Remote Play flow: a 1,721-character `GDREMOTE2` invitation produced a 1,306-character `GDREMOTEANSWER2` response, the host accepted Player 2, both profiles reported two players, video attached, and 18 Player 2 controller-input events reached the host.
- Both sessions terminated cleanly. No invitation payload, password, peer identifier, or private path is committed in this evidence.

### GameDeck Live LAN API hardening

- Commit `9ae4adf` removes pairing codes, private receiver URLs, and viewer identifiers from unauthenticated receiver-status responses.
- Pairing request bodies are capped at 8 KiB, signaling request bodies at 64 KiB, and the pending host queue at 128 events.
- Eight failed pairing attempts from one address are rejected normally; the ninth attempt within the 60-second window receives HTTP 429.
- Viewer removal now requires both the viewer identifier and active pairing code. Regression coverage verifies that an unauthenticated removal receives HTTP 403 and leaves the viewer connected, while an authorized removal succeeds.

### Runtime-cache streamed-byte boundary

- Commit `354b919` enforces a 1 GiB maximum against both advertised totals and bytes actually received by the release cache builder.
- The builder now fails closed when an upstream response omits or understates `Content-Length`, removes the oversized partial file, and does not retry a deterministic size-limit failure.
- `scripts/runtime-cache-stream-limit.test.mjs` provides focused regression coverage and is part of `npm test`.

### Playtest Night responsive and accessibility QA

- Commit `7b7ecba` moves the self-expiring Playtest Night strip into the first viewport before the hero.
- Countdown wording was verified for pre-live, the exact 61-minute state (`1 hour 1 minute`), live, and expired states; the strip hides at the configured end time.
- Desktop, tablet, and phone layouts showed no horizontal overflow. Event actions retain at least a 40 px desktop height and use a balanced two-column phone layout.
- The status announcement is atomic, outbound event links open safely, keyboard focus has a visible outline, and the pulse animation is disabled when reduced motion is requested.
