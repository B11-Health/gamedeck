# Archived community route

GameDeck no longer operates or depends on a Discord community. Old invitations, event links, channel names, and account instructions must not be used for support, matchmaking, onboarding, promotion, or sponsorship. No replacement Discord account or server is planned.

Use the current [GameDeck community guide](COMMUNITY.md), [GitHub Discussions](https://github.com/B11-Health/gamedeck/discussions), and [multiplayer tester thread](https://github.com/B11-Health/gamedeck/discussions/8).

This archived filename remains only so older documentation links lead to the supported GitHub-first route instead of failing silently.
