# Archived Discord community guide

GameDeck no longer depends on Discord for recruitment, matchmaking, support, onboarding, announcements, sponsorship, or product copy. This filename remains only so older links resolve to a clear migration notice.

Do not create a replacement GameDeck Discord account or server, attempt ban evasion, or send players to old invitations or channel URLs.

## Current community routes

- Multiplayer tester coordination: https://github.com/B11-Health/gamedeck/discussions/8
- General release feedback: https://github.com/B11-Health/gamedeck/discussions/7
- Completed multiplayer session report: https://github.com/B11-Health/gamedeck/issues/new?template=multiplayer_session.yml
- Compatibility report: https://github.com/B11-Health/gamedeck/issues/new?template=compatibility_report.yml
- Releases and checksums: https://github.com/B11-Health/gamedeck/releases/latest
- Private security report: https://github.com/B11-Health/gamedeck/security/advisories/new

Public GitHub coordination must not contain invitation codes, response codes, session tokens, IP addresses, precise locations, private paths, credentials, game files, firmware, keys, saves, or unnecessary identity data. Exchange active multiplayer codes through a private channel participants already trust.

See [GROWTH-001 — Verified multiplayer tester recruitment and proof capture](GROWTH_001_TESTER_RECRUITMENT.md) for the current community workflow, consent language, proof checklist, and publication approval gate.
