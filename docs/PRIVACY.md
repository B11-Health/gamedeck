# Privacy

GameDeck is local-first.

## Data on this device

GameDeck stores settings, favorites, recent-play timestamps, cached metadata, and cached artwork in Electron's per-user application-data folder. Game files and firmware remain in locations chosen by the user.

## Network activity

Network access can occur when the user browses an optional RGSX catalog, fetches public game metadata or artwork, or loads the small sponsor manifest. Sponsor creative is static and is not allowed to run scripts or collect identifiers through GameDeck.

## Advertising

Sponsor placements are contextual, clearly labeled, and user-disableable. GameDeck does not create advertising profiles, sell user data, or embed third-party ad scripts.

## Donations

Only public receiving addresses may be included in the app. Private keys, seed phrases, and encrypted keystores are excluded by design and by repository rules.

## Community testing and public reports

GameDeck does not collect multiplayer test data automatically. Participation in GitHub Discussions or Issues is voluntary and public. Testers should provide only broad environment details such as operating system, broad region, controller class, network class, accessibility settings, mode, route, and outcome.

Do not submit precise location, IP addresses, device names, private paths, game-library listings, invitation codes, session tokens, peer identifiers, credentials, ROMs, BIOS files, keys, saves, or copyrighted game assets. Public GitHub submissions may remain in repository history, mirrors, search indexes, or third-party caches even after editing, so sensitive information must never be posted.

Product triage permission is separate from promotional permission. A tester may allow an anonymous aggregate summary or GitHub-username credit through optional issue-form choices. Reuse of a specific screenshot, clip, or quote requires separate approval for that asset and a privacy review before publication. GameDeck does not promise compensation or public credit for testing unless the maintainer approves a separate written offer.

## Removal

Uninstalling GameDeck removes the application. Cached settings and artwork may remain in the operating system's application-data folder until the user deletes that folder. GameDeck never deletes a game library during uninstall.
