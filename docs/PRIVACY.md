# Privacy

GameDeck is local-first.

## Data on this device

GameDeck stores settings, favorites, recent-play timestamps, cached metadata, and cached artwork in Electron's per-user application-data folder. Game files and firmware remain in locations chosen by the user.

## Network activity

Network access can occur when the user browses an optional RGSX catalog, fetches public game metadata or artwork, or loads the small sponsor manifest. Sponsor creative is static and is not allowed to run scripts or collect identifiers through GameDeck.

## Advertising

Sponsor placements are contextual, clearly labeled, and user-disableable. GameDeck does not create advertising profiles, sell user data, or embed third-party ad scripts.

## Donations

Only public receiving addresses may be included in the app. Private keys, seed phrases, and encrypted keystores are excluded by design and by repository rules.

## Removal

Uninstalling GameDeck removes the application. Cached settings and artwork may remain in the operating system's application-data folder until the user deletes that folder. GameDeck never deletes a game library during uninstall.
