# GameDeck UIUX Release Copy

Production evidence: `main@31e606c`

## GitHub / long-form

GameDeck now has console-themed cinematic environments, stable selected-game controls, and stronger game-launch diagnostics.

The new spotlight keeps Play, Multiplayer, Save, Artwork, Details, and Remove visible across tested desktop and narrow widths. Actions meet a 44-pixel minimum target, theme transitions respect reduced motion, and controller and keyboard navigation remain first-class.

GameDeck also improves mixed-system classification, archive integrity checks, firmware guidance, managed-runtime selection, and reproducible FinalBurn Neo and MAME launch repair.

The exact production sequence passed the complete repository gate and a four-viewport Electron geometry test. Community playtesting is open in GitHub Issue #9.
