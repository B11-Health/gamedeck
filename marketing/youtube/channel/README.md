# GameDeck channel assets

These assets are derived from the official GameDeck emblem and cinematic brand system.

| Asset | Intended use |
| --- | --- |
| `gamedeck-youtube-avatar.jpg` | YouTube profile image |
| `gamedeck-youtube-banner.jpg` | YouTube channel banner |
| `gamedeck-video-watermark.png` | Video watermark |
| `gamedeck-launch-thumbnail.jpg` | Launch-video custom thumbnail after channel verification |
| `gamedeck-end-card.jpg` | Trailer and video end card |
| `gamedeck-stream-starting.jpg` | Stream waiting screen |
| `overlays/*.png` | Timed feature callouts used by the motion trailer |

The channel currently requires one-time phone verification before YouTube accepts a custom thumbnail. The thumbnail remains ready in this directory.
