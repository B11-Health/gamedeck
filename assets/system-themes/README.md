# GameDeck system themes

These original panoramic WebP backgrounds provide console-aware environmental art for the Library spotlight. They were created for GameDeck and contain no game covers, recognizable characters, brand logos, official console photography, or copied console artwork.

- Nintendo classic: NES, Famicom Disk System, Super Nintendo, Satellaview, Sufami Turbo
- Nintendo polygon: Nintendo 64, GameCube, Wii, Wii U
- Nintendo handheld: Game Boy, Game Boy Advance, Nintendo DS
- Sega 16-bit: Master System, Genesis, 32X, Game Gear
- Sega 3D: Sega CD, Saturn, Dreamcast
- PlayStation: PlayStation, PlayStation 2, PSP
- Arcade: FinalBurn Neo and MAME
- Retro: Atari 2600 and PC Engine
